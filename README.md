# DEMOS Manga Sources

Independent Arabic source repository for DEMOS Manga. This repository includes only extensions explicitly marked `ContentWarning.SAFE` in their source metadata. Unclassified and adult/explicit sources are excluded.

## Add to DEMOS Manga

Repository index: `https://raw.githubusercontent.com/Maxofmax20/demos-manga-sources/repo/index.pb`

Add that URL in **Extensions → Extension repositories**. The repository is independent of the Android app release cycle; source updates are published separately.

## Scope

- Arabic-language extensions only.
- Only sources explicitly marked SAFE in extension metadata.
- Source builds and repository publication are handled by GitHub Actions.
- Source availability and compatibility depend on the upstream websites and may change.
